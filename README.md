# Lagnajita Das — Tech Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript. The site includes an interactive **Superpower Discovery Machine** as its creative feature.

## Project structure

- `index.html` — portfolio content and sections
- `style.css` — responsive visual design
- `script.js` — mobile navigation and interactive discovery machine
- `assets/profile.jpg` — profile image
- `assets/certificates/` — certificate files
- `projects/scientific-calculator/` — browser demo and Java source files for the calculator project

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Deploy with AWS Amplify Hosting

1. Create a **new GitHub repository** for this challenge version. Keep the previous `portfolio` repository unchanged.
2. Upload the contents of this project folder to the new repository's root (so `index.html` is at the repository root).
3. In AWS Amplify, choose **Host web app** and connect the new GitHub repository and branch.
4. For this static HTML/CSS/JavaScript site, use the default no-build configuration if prompted; the publish/root directory should be `/` (repository root).
5. Deploy and wait for the build to complete.
6. Open the generated Amplify URL and test all navigation, project links, certificate links and the discovery machine on desktop and mobile.
7. Keep the live URL available throughout the judging window.
